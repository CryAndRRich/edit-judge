# The GPU server of the live demo (README, "GPU server"): the web app (apps/web/) with the real models on CUDA:
# Qwen2.5-VL-7B, Grounding DINO + SAM 2.1, the 20 editors the assistant can run (apps/web/download.py) and our
# scorer mlp-siglip, all in one environment and one process.
#
# Install in this order (a fresh conda env, Python 3.11: basicsr, bundled by CodeFormer and GFPGAN, imports
# distutils, which Python 3.12 removed):
#   pip install torch==2.14.1 torchvision --index-url https://download.pytorch.org/whl/cu130   # Blackwell (sm_120)
#   pip install -r requirements/server.txt
#   pip install --no-deps gfpgan==1.3.8 facexlib==0.3.0
# gfpgan and facexlib go without their dependencies: their pins pull in tb-nightly, lmdb and yapf, none needed for
# inference (src/editors/models/gfpgan.py). Torch is not listed here so that pip keeps the CUDA 13.0 build.
#
# On Kaggle the editors found most of these preinstalled; a fresh environment does not, so every module the
# wrappers, the repository code they download (src/editors/models) and the scorer import is listed.
# FLUX.2 klein (diffusers 0.37.1) is not in the live demo, so its pin is not needed and everything shares one
# environment (on Kaggle, realesrgan, vosr and gfpgan had their own: requirements/editors.txt).
